# Example: Ghost Link Failure

## Situation

A user likes some science fiction and action works. The system repeatedly recommends a shallow superhero film only because the genre surface appears similar.

The user does not click.

## Bad interpretation

- Try another thumbnail.
- Push the same category again.
- Treat non-click as simple ranking failure.

## C-mode interpretation

The non-click may be a strong reaction point.

Possible reasons:

- genre is not the problem
- the emotional temperature is wrong
- the cast, image style, title, or marketing shell creates refusal
- the user responds to character weight, world distance, residual conflict, or position changes, not surface genre

## Principle

A failed recommendation is not only noise.  
Handled properly, it becomes part of the reaction point cloud.
